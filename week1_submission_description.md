# Week 1 Submission Description

This report documents a complete data acquisition, cleaning, and preprocessing workflow implemented in Python. A publicly available Iris dataset from the UCI Machine Learning Repository is used as the source dataset. The project begins by acquiring the dataset programmatically and examining its structure, data types, descriptive statistics, duplicate records, and missing values. Because the original UCI Iris dataset is documented as having no missing values, a separate controlled working copy is created to demonstrate realistic data-quality problems without altering or misrepresenting the source data. The controlled copy contains missing observations, inconsistent categorical labels, an invalid negative measurement, and deliberately extreme numerical values.

The cleaning workflow addresses each issue systematically. Categorical labels are standardized using trimming and lowercase conversion. Invalid negative measurements are treated as missing because they are outside the physically meaningful range of the measurements. Missing numerical values are imputed using within-class medians, with a global-median fallback for robustness. Potential numerical outliers are identified using the interquartile range (IQR) method and capped at statistically derived lower and upper bounds. Duplicate records are checked and removed where present. After cleaning, the numerical features are standardized using StandardScaler so that variables measured on different scales can be used more consistently in subsequent analytical or machine-learning workflows.

The report also discusses the rationale, limitations, and potential effects of every preprocessing choice. Visual diagnostics and validation outputs are included to compare the dataset before and after cleaning. The complete workflow is reproducible through the supplied Python script and dependency file, making the project suitable for further exploratory analysis and modelling.
